## 7. THE PARK-REMOVAL BLOCKER — escalated, RULED (§9), and LANDED

**RULING (recorded as §9 in the contract refresh, BINDING): option 3+1 HYBRID — read-set-driven epoch mirror + dispatch-scoped lazy-park fallback.** As landed (commit 6/8):
- **The SYNCED mirror (option 3):** `CSplitLuaHandle` carries a read-set-driven mirror of the SYNCED globals the draw side reads. The proxy's `__index` registers every dispatch-window key on first touch; the SIM thread mirrors the registered keys' SCALAR `_G` values at its produce edge (step p7c; the paused-idle path services first-touch keys dirty-gated); the consumer commits staged→served with the epoch (barrier step 3d'); subsequent window reads serve from the held epoch's mirror (counted as `SYNCED table read (mirror)`). **FIDELITY (per the ruling, a correctness upgrade, not a deviation):** the mirrored value is the epoch edge's — it matches the deferred events' frame window, which is MORE master-faithful than the live read the parked dispatch used to make (master's handlers ran mid-frame-N; the mirror is frame-N state).
- **The lazy park (option 1 fallback):** reads the mirror cannot serve (first touch before the next edge, non-scalar values — tables/functions) engage `CGame::AcquireLazyDispatchPark`, held to the barrier's window close; `ErrorOnCrossHop`'s parked-window branch counts the engage (the `SYNCED table read` counter = the engage telemetry). It deliberately performs no valve service (it can run INSIDE the barrier's dispatch; a valve-parked sim is quiescent, which is all the read needs). Out-of-window draw-context cross-hops keep the hard error.
- **The park removal:** `CGame::Draw` no longer parks. Producer/consumer exclusion is the §3.2 pacing stamp, made explicit as `SignalEpochConsumeComplete` at the old release point (it also publishes the backpressure boundary frame via `SimDrawSplit::PublishBoundaryFrame` — the exact value `ReleasePause` published there, so 44a pacing/backpressure semantics are preserved verbatim; the N-1-epochs rekey stays 44c).
- **The valve:** the in-place `valveLive` Flush/Drain is replaced by `ServicePoolValveOnce` — consume any published epoch through the NORMAL barrier, FORCE-produce the mid-frame tail into an emergency epoch on the main thread (the sim is parked mid-frame = quiescent; the produce contract explicitly allows main-with-quiescent-sim; the §7.7 dead rows come from the pending ledger, so §3.6a id-coverage holds for the tail batch by construction — NO live exception anywhere), consume it, `ReleaseAcked`. The Draw-top service resumes no-wait (`ResumeFromValveNoWait`); the `AcquireSimPause` loop keeps the waiting resume for lifecycle parks and skips servicing while a dispatch window is open (re-entrancy guard). `ReleasePause` preserves a VALVE park across a lazy/lifecycle release. Mid-frame emergency rows are a value-consistent momentary state — closer to master's mid-frame dispatch than the old valve's parked live reads. The full valve rekey (retirement-wait, no in-place service) stays 44c per the ruling.
- **`valveLive` RETIRED → the ScopedLiveException survivor set is EXACTLY the 8 audited (§5.12):** pregame `prePublishFallback` ×3, armed dual-run `liveLeg` ×3, query-reply-parked `simParkedInline` ×2 (all LuaSnapshotServe.cpp).

### The original escalation record (superseded by §9; kept for history)

### The blocker
Deferred sim-fired handlers read the `SYNCED` proxy (unsynced→synced lua_State cross-hop) as ordinary master behavior: measured full-length headful demand = **44,888 reads/game (ATG) / 44,569 (Rosetta) — `cus_gl4.lua:1898` (`SYNCED.itsXmas`) once per unsynced-gadget `GameFrame` ≈ every sim frame**, plus `system_info.lua:45` (pregame ×26) and `gui_awards.lua:298` (game end ×1). Stock pinned .sdp archives — not game-patchable for the gates. Under 44a these ran under the park (+ live exception); with the dispatch concurrent to the sim, a cross-state read touches the lua_State the sim thread is actively executing/GC-ing — genuinely unsafe, not contract noise. The research doc's disposition ("hard-error; SendToUnsynced mirroring is the replacement story") is a game-migration answer that contradicts the 0-lua-error gate on stock replays; §3.6 covers row/value serving only. It is very plausible this class was part of 38b's never-root-caused error storm.

Interim (landed, 2/6): cross-hops are PERMITTED and counted while `BoundaryShellWindowActive() && IsSimParked()` — safe by quiescence, keeps stock BAR working, and the counters are the ruling's demand data. Draw-callin cross-hops still hard-error.

### Options for the ruling (all pre-scoped, none improvised here)
1. **Dispatch-scoped lazy park:** on the first cross-hop inside a dispatch window, `RequestPause` and hold to the window close. Per-frame with cus_gl4 ⇒ parked ≈ dispatch-tail duration every frame + the mid-frame edge-wait latency on the DRAW thread (hitch class) — defeats the parked≈0 headline's letter; simplest mechanism.
2. **Synced-Lua execution mutex:** sim holds it across synced callin execution + synced-state GC; the cross-hop read takes it briefly. Preserves parked≈0; violates the standing no-lock ruling (operator waiver needed); widget-timing-dependent contention.
3. **Read-set-driven synced-globals mirror:** producer captures the values of previously-read SYNCED keys per epoch; first-read of a new key parks once. Zero steady-state parks/locks; scalar keys are trivial (`itsXmas`) but nested-table reads (gui_awards) need a deep-copy design — a real serving sub-project.
4. **Accept a permanent dispatch-phase park** (44a's residual park narrowed to the dispatch steps only) — re-scopes the program's success metric.

### The remaining park-removal commit (small, once ruled)
All prerequisites are landed by 3/6. What remains: drop `AcquireSimPause`/`ReleaseSimPause` from `CGame::Draw` (keep lifecycle parks), rekey backpressure (`SimDrawSplit::PublishBoundaryFrame(heldEpoch.lastSimFrame)` at acquire), move the consume-complete stamp from `ReleaseSimPause` to an explicit signal at the old release point, rework the valve service into consume+force-produce-in-place (sim parked at valve; `ProduceEpochAtSimEdge(force)` from the main thread + `ReleaseAcked` + a no-wait valve resume), retire `valveLive`, and implement the ruled cross-hop mechanism.
