## §1 What this branch does (the one-paragraph version)

The sim and draw phases run on their own threads with near-zero synchronization. The SIM thread produces a complete, versioned, immutable **epoch** at its own frame edges (all snapshot row namespaces, render-event + deferred-dispatch records, map-mirror payloads, command-queue/piece caches, rules-params, query replies, a SYNCED-globals mirror), into an N=3 refcount-retired ring. The DRAW thread consumes the newest complete epoch and **never parks in gameplay** (parks per game: ~21–29, all lifecycle — saves, Lua handle reload, teardown, rare input-gated reads). Every unsynced/draw-context read of sim state is served from the published epoch (or explicitly classified value-safe/denied) — never read live. Hard invariants maintained throughout: (1) flag-OFF (`SimDrawSplit=0`) is byte-identical to the base branch — full sync compatibility; (2) the full Spring Lua API is served — no callout was removed or nil-broken; (3) user-visible behavior deviations are enumerated and advisory-UI-only (each recorded in the ruling docs).

Headline numbers: parked window ~13.5 ms (pre-flip, FF catch-up) → ~2.1–2.8 ms (44a) → **≈0 (44b/44c: ~0.2 s parked per whole game)**. `sanctionedLive` (the live-read exception table) is EMPTY; strict mode over full replays shows ZERO denials; the armed id-coverage gate shows zero unservable record ids (186k/280k checks per replay).

## §5 Test recipes (how to prove a change is safe)

The universal runner: `test/callout-diff-gate/run_diff_gate.sh "<abs demo path>" <label> build/spring`, cwd = worktree root, `SPRING_DATADIR=<datadir>`. Env knobs: `DG_ARM=1` arms the snapshot diff-gate, `DG_FF=1` fast-forward (default in the script), `DG_QUIT_FRAME=0` full length. First-ever run in a fresh datadir only REGISTERS the driver widget — re-run once. Headful adds `DISPLAY=:0 SDL_VIDEODRIVER=x11 SDL_AUDIODRIVER=dummy ALSOFT_DRIVERS=null`.

1. **Flag-OFF byte-identity (sync compatibility)** — the non-negotiable gate for ANY change reachable flag-off: `SimDrawSplit=0`, `DG_ARM=0`, full-length, both replays → `grep -c DESYNC infolog.txt` = 0. Any DESYNC = your change altered synced state/ordering.
2. **Armed diff-gate (served-value bit-correctness)** — `SimDrawSplit=0`, `DG_ARM=1`, full-length: runs every serving twin against the live value and every mirror/row field-pass → the infolog must show `[SnapshotDiffGate] ===== report … : PASS (0 mismatches) =====`. Required whenever you add/change a served row, mirror, or twin. New rows must join `SnapshotHash.cpp` + the `SnapshotDiffGate` field passes.
3. **Strict contract (serving completeness)** — `SimDrawSplit=1`, `SplitDrawContract=2`, full-length: the contract dump must show zero `denials` on every callout and `[EpochStats] idCoverage: … violations=0`. Any denial = a draw-context read hit an unserved/unclassified callout — serve it or classify it, never carve an exception.
4. **Headful flag-ON (THE gate that catches what headless can't)** — `SimDrawSplit=1`, full-length, serial: headless drops the GL4 widgets entirely, so draw-side serving bugs ONLY surface headful. Pass = rc 0, reaches ~f=44540 (Rosetta) / ~f=44860 (ATG), 0 DESYNC, 0 lua errors beyond §4 baselines, 0 `Invalid Feature id`, `idCoverage violations=0`. Error signatures to grep for (the historical failure classes): `attempt to`, `Error in`, `FeatureCreated`/`UnitCreated`/`UnitDamaged` nils, `gl.SetFeatureBufferUniforms`, `ZOMBIE instanceID`. Draw-timing-flaky classes exist — treat ANY single-run occurrence as real (root-cause, don't re-roll).
5. **Telemetry reads (in every flag-ON infolog at teardown):** `[SimParkStats]` (parks should be ~20–30/game, all lifecycle — a jump means a new park); `[SimPauseSurvey]` (per-site park-engage counts — a per-frame count at any site is a regression); `[EpochStats]` (per-channel bytes, ring occupancy, idCoverage); `[PoolValveStats]` (valve engages — normally 0); `[BackpressureStats]` (ring-blocks — should be 0 under FF per the §5.13 carve-outs; nonzero under FF = the free-run carve-out broke); mirror-served / lazy-park counters (`SYNCED table read` line — lazy engages should stay ~dozens, not thousands).
6. **Forced-valve smoke** (when touching deleter/valve/ring lifetime): the valve never engages naturally in these replays — add a temporary uncommitted pressure hack (see PR 44c's `DG_VALVE_TEST` approach in its design record: shrink pool headroom so `Defer()` trips), run headless to a few thousand frames, verify no deadlock/hang + `[PoolValveStats]` engages > 0 + clean exit, then REVERT the hack and rebuild before real gates.
7. **TSan segment** (when touching cross-thread machinery): `build-tsan/` exists in the worktree (`USE_TSAN=ON`, `USE_MIMALLOC=OFF`). Gotchas: an `aligned_alloc` abort needs the documented build-only accommodation (see the battery agent notes / MemoryOverride), set `HangTimeout=-1` (watchdog kills the ~100× slower run), `TSAN_OPTIONS=allocator_may_return_null=1 halt_on_error=0`, needs `DISPLAY=:0`, run only a SEGMENT (`DG_QUIT_FRAME=<few thousand>`). Compare findings against the tolerated §C torn-read families in the research doc — new races on epoch/deleter/queue machinery are real bugs.
8. **Windowed/live testing**: replays never drive interactive input (cursor, build placement, orders, executor parks). Those paths are only covered by a live skirmish with a human — flag anything in that area for the operator rather than claiming replay coverage.

## §6 Debugging: symptom → likely subsystem

- **DESYNC flag-OFF** → your change is reachable with the split disabled; find the sim-side edit that isn't wrapped in `if (SimDrawSplit::Enabled())` (or equivalent). The split code must be flag-off inert, byte-for-byte.
- **Widget lua error, flag-ON headful only, create/damage/event callin** (nil featureDef, compare-nil, etc.) → the 38b class: a deferred handler read something its epoch can't serve. Check `[EpochIdCoverage]` first (a violation names the record); then the event-time capture inventory (44b design record) — the event may need a fire-time value capture; then DEAD_THIS_BATCH row validity for died-in-batch ids.
- **`Invalid Feature id` / healthbars nil-storm** → died-in-batch retention broken: drawer render records must retain dead ids through the dispatch window (cleared at ack); also check the flip→lockstep teardown consume (orphaned sealed batches at quit — 44b commit 7b/8 class).
- **Null-def crash / garbage row values for a dead unit** → dead-row genuineness: rows for dying ids must be extracted from their DeferredObjectDeleter shells at the frame edge (§7.7), not trusted from a stale slot.
- **Heap corruption (mimalloc asserts, `mi_block_next` garbage)** → cross-thread ownership violation: something draw-owned ran on the sim thread or vice versa (44b lesson: GuiTraceRay/pick-grid is DRAW-side; synced Lua is SIM-side). Bisect by commit, then gdb.
- **FF suddenly slow / sim stalls** → `[BackpressureStats]` ring-blocks (free-run carve-out broken) or `[PoolValveStats]` waits (shell retirement stuck → is the consumer acquiring/retiring epochs?). Post-PR-46 also check `ffBackstopExits` (huge = draw stopped acquiring, the full-throttle loop is running on its 250ms backstop) and whether `SplitFullThrottleConsume()`'s carve-outs still hold.
- **A new park / parked-time jump** → `[SimPauseSurvey]` names the site; per-frame sites must be served (see prereq D/E precedents), rare input-gated ones may be accepted with the operator's sign-off.
- **SYNCED.* read misbehaving in a widget** → the epoch mirror serves registered scalars; non-scalar/nested reads take the lazy park (counted). A mirror-served value is ≤1 sim frame stale BY DESIGN (more event-faithful than live). Check `LuaSyncedTable.cpp` counters.
- **Stale/wrong served value with no error** → run the armed diff-gate (recipe 2); a mismatch pinpoints the row/twin. Remember its one landed trap: the armed dual-run must restore original Lua args before the twin (`74122439c3`).
- **Something works flag-OFF and single-threaded flag-ON but breaks live** → look for a `Generation()`/`HeldEpochId()` cache keyed wrong, or a consumer reading a producer-owned singleton that became per-slot (43/44a design records list the per-slot conversions).

## §7 Making future changes (the rules that kept this working)

- **The prime directive:** a draw-context read of sim state gets SERVED through the published epoch — never approximated, never left live, never null-checked around. If serving is genuinely infeasible draw-side, the pattern is a sim-side query/reply channel (precedents: weapon trace tests, placement tests, default-command). `DenyLiveRead` + strict mode are the tripwire — a strict-mode denial after your change is a bug by definition.
- **Serving a new callout / adding a row:** follow the §E.2 recipe in `sim-draw-epoch-publish-specs.md`: extract at the producer (due-checked), add SnapshotHash + a SnapshotDiffGate field-pass, write the twin, dual-run it armed, delete any live path, enumerate order/staleness deviations. Every mutation path to mirrored state needs a choke-point funnel + a grep-audit table in the commit (a bypassable choke is a blocking review finding).
- **Flag-off byte-identity:** wrap behavior changes in the split flag; when in doubt, run recipe 1 before anything else. The armed diff-gate (flag-off) is the cheap full-proof.
- **Lifetime changes** (deleter, shells, DEAD_THIS_BATCH, ring): re-run the forced-valve smoke + a TSan segment; these are the two subsystems where "compiles + resims clean" means least.
- **Escalation culture:** ambiguities got operator rulings, recorded in the specs amendments and contract-refresh §7/§8/§9. Don't contradict a recorded ruling; add new rulings to the record rather than deciding silently. Enumerated deviations (documented, advisory-only) are how user-visible differences are handled — silent behavior change is not acceptable.
- **Gate economy** (operator-ratified): per-landing = build + one armed diff-gate + one strict + ONE headful flag-ON full-length (alternate replays between landings); the expensive stuff (multi-run headful matrix, TSan, both-replay everything) only at milestones/stack-end. Headless legs concurrently in separate datadirs; headful serial.
- The operator merges `epoch-integration` → `bruno/poc-split-sim-draw` at a moment of their choosing — never do it for them.
